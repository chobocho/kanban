  • 툴바의 🗄️ 버튼으로 보관함을 열어 보관된 카드를 복원하거나 영구 삭제(확인 팝업)할 수 있습니다. 복원 시 원래 리스트로 돌아가며, 그 리스트가 삭제되었다면 첫 리스트로 복원됩니다.
  • 데이터 모델에 Board.archived를 추가했고, 이전 버전 데이터도 정규화 시 빈 배열로 안전하게 채워집니다. (잘못된 보관 항목은 자동 제거)
  • 보관/복원/영구삭제는 컬럼 외부의 보관함을 변경하므로, 실행 취소 이력과의 충돌(중복 카드)을 막기 위해 해당 작업 시 이력을 초기화합니다.
  • 단위 테스트 5건(보관·복원·원본 리스트 삭제 시 대체 복원·영구삭제·정규화)과 브라우저 스모크 테스트(보관→보관함 표시→복원)를 추가했습니다.

  • 되돌리기는 최대 8단계까지 지원합니다. 가장 오래된 단계는 자동으로 버려져 메모리가 일정하게 유지됩니다.
  • 키보드 단축키도 지원합니다: 실행 취소 Ctrl/Cmd+Z, 다시 실행 Ctrl/Cmd+Shift+Z 또는 Ctrl+Y. (카드 편집 중에는 텍스트 입력을 방해하지 않습니다.)
  • 되돌리기 대상은 활성 보드의 내용(카드·리스트)이며, 보드를 전환·생성·삭제하거나 JSON을 가져오면 이력이 초기화됩니다.
  • 되돌릴/다시 적용할 항목이 없으면 해당 버튼은 비활성화됩니다.
  • 순수 로직 모듈(history.ts)로 분리하여 단위 테스트 7개를 추가했고, 브라우저 스모크 테스트에 Undo/Redo 검증을 포함했습니다.
