달력에서 드래그로 날짜 이동 2026-07-10

  • 달력의 일정을 드래그해서 다른 날짜 칸에 놓으면 카드의 날짜가 그 날짜로 이동합니다. 시각(시:분)은 그대로 유지되고, 마우스와 터치 모두 지원합니다.
  • 일정 종류별 동작: 마감⏰/시작🚩 점 일정은 해당 날짜만 이동, 기간 바의 시작 조각은 시작일만·끝 조각은 마감일만 이동(기간 조절), 중간·하루짜리 조각을 끌면 기간 전체가 길이를 유지한 채 평행 이동합니다. 시작일이 마감일을 넘어서는 이동은 거부됩니다.
  • 드래그 중에는 잡은 일정이 반투명해지고 놓을 칸이 강조 표시됩니다. 살짝 움직인 경우는 클릭으로 처리되어 기존처럼 카드가 열리고, 드래그 후에는 카드가 열리지 않습니다. 날짜 이동은 실행 취소(undo) 대상입니다. (활성 보드가 아닌 보드의 카드는 저장만 하고 실행 취소 이력에는 넣지 않습니다)
  • 날짜 계산을 순수 함수 computeDropPatch로 분리해 단위 테스트 3건(점 이동·기간 평행 이동·기간 조절/역전 거부)을 추가했고, 스모크 테스트로 드래그 이동과 드래그 후 카드가 열리지 않음을 검증했습니다. (단위 112/112, 스모크·릴리스 번들 전체 통과)

  • 스모크 테스트로 날짜 클릭 → 제목 입력 → 해당 칸에 일정 표시 → 보드에 카드 추가 → 실행 취소까지 검증했습니다. (단위 109/109, 스모크·릴리스 번들 전체 통과)

  • 같은 날짜 칸 안에서는 기간 바가 점 일정(시작일/마감일 단독)보다 위에 정렬되어 여러 일정이 겹쳐도 읽기 쉽습니다. 마감일이 시작일보다 앞선 비정상 데이터는 기존처럼 점 두 개로 표시됩니다.

터치 환경 드래그 앤 드롭 수정 2026-06-26

  • 폴드7 등 터치 화면에서 카드·리스트 드래그가 동작하지 않던 문제를 수정했습니다. 카드와 리스트는 스크롤 영역이라, 브라우저가 손가락 끌기를 스크롤로 가로채 드래그가 취소(pointercancel)되고 있었습니다.
  • 터치는 짧게 누르고 있다가(약 200ms) 끌면 드래그가 시작되고, 빠르게 스와이프하면 기존처럼 스크롤됩니다. 마우스/펜은 종전대로 살짝만 움직여도 바로 드래그됩니다.
  • 드래그 중에는 네이티브 touchmove를 preventDefault하여 화면 스크롤이 끼어들지 않도록 했습니다. (pointermove의 preventDefault만으로는 터치 스크롤을 막지 못함)
  • 두 번째 손가락이 닿으면 진행 중이던 드래그/대기를 취소해 두 손가락 확대·축소(pinch)로 자연스럽게 넘어갑니다.
  • 실제 터치 이벤트로 누르고-끌기 이동과 빠른 스와이프=스크롤(이동 안 함)을 검증하는 항목을 브라우저 스모크 테스트에 추가했습니다. (마우스 드래그 회귀 없음)
